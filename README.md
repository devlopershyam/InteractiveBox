# InteractiveBox
This project features a responsive and interactive product pricing category with size and color for an e-commerce platform. It demonstrates a styled pricing offer with dynamic discounts and size/color selection options.


📸 Screenshot
![image](https://github.com/user-attachments/assets/e37ab6d8-7ff8-4fce-813c-7a8cb9832724)

Dynamic Pricing Tiers
Offers 1, 2, or 3-unit purchase options with corresponding discounts:

1 Unit – 10% Off ($10.00 USD)

2 Units – 20% Off ($18.00 USD) – Most Popular

3 Units – 30% Off ($24.00 USD)

Customizable Options
Users can choose size and color combinations for each unit.

Price Comparison Display
Original prices are shown with strikethrough for better visibility of the discount.

Visual Highlighting
The most popular deal is clearly marked for marketing emphasis.

Update Total Value
By click any price category (Unit Box) it updated total value.
